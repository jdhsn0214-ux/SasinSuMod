# 사신수 무기 모드 (Forge 1.20.1)

## 현재 포함 기능
- 청룡의 검, 백호의 도끼, 주작의 단검, 현무의 창
- 사신수 테마의 3D 큐브형 무기 모델
- 우클릭 시 무기별 광역 스킬과 궁극기급 파티클 연출
- 무기별 소환 영령: 청룡(팬텀), 백호(늑대), 주작(앵무새), 현무(거북이)
- 소환 영령은 플레이어 주위를 선회하고 주변 적대 몬스터를 공격하며 약 20초 뒤 사라짐
- 현무 방어/흡수/재생 강화
- 무기가 크리에이티브 전투 및 도구 탭에 표시됨
- 서버 측 피해 판정과 무기별 재사용 대기시간

## 참고
소환 영령은 현재 바닐라 몹 모델을 사용한 프로토타입이며, 완전히 독립된 사신수 모델/리깅 애니메이션은 아직 포함하지 않습니다. 공격 동작은 기본 플레이어 휘두르기와 스킬 파티클 연출을 사용합니다. 전용 UI 및 고급 프레임 애니메이션은 후속 개선 항목입니다.

## 빌드
- Minecraft 1.20.1
- Minecraft Forge 47.2.0
- Java 17
- GitHub Actions가 main 브랜치 변경 시 자동으로 빌드합니다.
- 성공한 Actions 실행의 Artifacts에서 `SasinSuMod-JAR` ZIP을 내려받아 내부 JAR를 `.minecraft/mods`에 넣으세요.
