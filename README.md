# 사신수 무기 모드 (Forge 1.20.1)

## 현재 구현 목표: 스킬 시스템 우선
- 청룡의 검, 백호의 도끼, 주작의 단검, 현무의 창
- 무기마다 서로 다른 4가지 스킬 (총 16개)
- 우클릭: 일반 스킬
- 웅크리기 + 좌클릭: 강력한 스킬
- 웅크리기 + 우클릭: 궁극기
- 웅크리기 2회 연속: 특수 공격
- 사신수 소환 몬스터 기능은 제외
- 서버에서 피해 판정과 개별 스킬 쿨타임 처리
- 궁극기는 넓은 범위의 다층 파티클, 폭발, 사운드 및 무기 테마별 효과를 사용

## 스킬 테마
- 청룡: 용의 기운, 전격, 용의 파동과 돌진
- 백호: 발톱 연격, 충격파, 대규모 참격
- 주작: 화염 연속 공격, 화염 폭풍, 불꽃 돌진
- 현무: 방어막, 설빙 충격파, 강력한 방어 강화

## 아직 후속 작업이 필요한 부분
- 스킬 연출은 현재 파티클/피해 중심의 구현이며, 전용 3D 무기 모델과 프레임 단위 애니메이션은 아직 완성되지 않았습니다.
- 실제 게임에서 입력 감지, 멀티플레이 동작, 밸런스와 빌드 성공 여부를 테스트해야 합니다.
- 커스텀 스킬 UI와 쿨타임 표시도 아직 없습니다.

## 빌드 환경
- Minecraft 1.20.1
- Minecraft Forge 47.2.0
- Java 17
- GitHub Actions가 main 브랜치 변경 시 자동 빌드합니다.
- 성공한 Actions 실행의 Artifacts에서 `SasinSuMod-JAR` ZIP을 내려받아 내부 JAR를 `.minecraft/mods`에 넣으세요.
